☕ Coffee Sales Analysis — Excel Dashboard

📌 Project Overview

This project analyzes coffee shop sales data using Microsoft Excel to identify sales trends, customer purchasing behavior, and product performance.

The project covers the complete workflow from raw data preparation and cleaning to analysis and dashboard development.

🎯 Business Questions

- How do sales change over time?
- Which coffee products generate the most sales?
- Which product categories perform best?
- What are the key sales trends?
- Which areas of the business should receive more attention?

🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Transformation
- Pivot Tables
- Data Analysis
- KPI Analysis
- Dashboard Development
- Data Visualization

📊 Dashboard

The final dashboard provides an interactive overview of coffee sales performance and helps identify important sales trends and product-level insights.

Dashboard file: "Coffee_Sales_Dashboard.xlsx"

🔍 Analysis Process

1. Imported and reviewed the raw sales data
2. Cleaned and prepared the dataset
3. Created calculated fields for analysis
4. Built Pivot Tables to summarize sales data
5. Analyzed sales trends and product performance
6. Designed the final Excel dashboard

💡 Key Findings

Key findings from the analysis are presented through the dashboard, including sales trends, product performance, and other important business KPIs.
